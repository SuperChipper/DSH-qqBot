# Blue V3：原有“home”音区判断纠正与实体声补强

用户在V2反馈158–161秒仍发虚、177–180秒转调错误，并进一步明确后者是“长音中间突然高一八度”。
此前按622 Hz高音保留并补高起尾的方案选错了角色演唱音区，已撤回，不能继续以旧目标自检PASS为正确旋律证据。

## 177–180秒：恢复连续低音区

原声pYIN/RMVPE约622 Hz，独立CREPE约311 Hz；原声存在强622 Hz周期，偶次谐波占优。
这些物理周期、估计器置信度都不能单独确定听者要保留的旋律音区。本轮依据用户明确的突变方向，
将整段“home”接回前后约310 Hz的连续音区，而不是再把高音起尾补齐。

175–181秒带上下文重唱，任务`b8c43d1bce154361894b72646d478915`：

- 177.56–179.45秒内，目标>450 Hz的164帧降一个八度；保留已经处于低音区的尾音。
- 起音仅在原有有声帧中作短中值平滑，原有清音/换气不填入F0。
- index 0.6、presence 2、debuzz 0.95，伴奏不移调。
- 最终拼接177.48–179.80秒，80 ms交叉淡化。
- 以旧长音中央的RMS匹配新长音，避免直接用上下文增益造成修正音区后异常增响。

中央177.95–178.90秒的输出中位数从约622降为约311 Hz。整段与中央窗口均未再检出相对新目标的八度级错误。
仍需听感确认细节，不把目标跟随与旋律判断混为一谈。

## 158–161秒：不改音高，补主体并减轻气噪

V2该段目标跟随稳定，核心约560 Hz；主体能量较源弱、5.5 kHz以上噪声偏多。
本轮直接处理已有换声轨，不再次更换旋律或混入原唱波形：

- 以900 Hz附近宽带钟形EQ补主体，最高约2.2 dB。
- 目标有声段内减弱非谐波高频成分，保护F0整数倍附近的谐波，最大衰减6 dB。
- 使用原声仅作慢速响度包络参考，额外补偿上限3 dB；不回填原唱音色或高频残差。
- 只拼接157.80–161.10秒，其他母带采样保持不变。

处理前检查显示158–160秒主体/RMS约补2 dB，气噪频带约减少3.5 dB；
160–161秒RMS约补1.9 dB、气噪频带减少约2.4 dB。具体最终结果见`tmp/rvc-blue-v3/report.json`。
音高目标在此段不变，处理后没有检出新增八度错误。这是局部音色/响度修整，不能仅靠指标认定“发虚”听感完全消失。
