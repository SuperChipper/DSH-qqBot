## 管线修改

只增加一个有界的长音半频复核，保留默认 breath：

1. 检测有声段内八度级变化，触发时才额外提取一次 CREPE。
2. 参考轮廓至少持续 500 ms；可靠帧覆盖和周期性须合格，轮廓音区须稳定。
3. 主曲线在同一参考轮廓中，须有至少 120 ms 已经处在参考上音区的锚点。
   只有一个更高估计、却没有主曲线锚点时，不自动把低音整句升高。
4. 修复该长音内的半频小岛，包括零碎的低八度帧。参考短置信缺口最多连接 120 ms，
   须两侧连续支持、且不能越过原清音。
5. 只上修，不下调已确认高音、不填换气；若新八度跳变数增加，退回原曲线。
6. 人工 F0 完全绕过；该步骤在移调前执行，现有 pitch 和伴奏规则不变。

代码：`scripts/singing-service/pipeline/f0_path.py`、`pipeline.py`。
输出 `02_f0.sustain.csv` 的参考与结果为移调前 Hz；最终 `02_f0.csv` 仍为含移调的合成目标。

## 158–161 秒的独立音色结论

该问题与八度错误分开看，V6 未更改这段音色处理。
本轮比较了同一分轨、RVC 原始输出、polish、此前 body EQ、V4 最终人声，并逐帧归一化后比较频谱，
避免把响度差误当成频色变化。

- **158.2–159.7 秒并非简单的整段高频被低通。** 所选 RVC 原始输出的 1.6–4 kHz 相对主体
  只比源低约 0.4 dB，但 2.2–3.4 kHz 这小段相对主体少了约 16.9 dB，能量转移到了其它谐波。
  因此更准确的描述是 RVC 重分配了谐波/谱包络，穿透感所在的频段明显变薄。
- polish 在这段增加了约 2 dB 的中高频比例。后加的气声/高频衰减又减少约 3.7 dB 的
  4–8 kHz 比例，因此原来为压气声所加的处理也可能削弱亮度，不应继续加重。
- **160.4–160.85 秒确有明显的转换后变闷。** RVC 原始输出的 1.6–4 kHz 相对主体比源少约
  10.8 dB；这个差异在 polish 前已经存在，不能归咎于最后 MP4 编码。
- 不能据一次 LPC 数字认定“共振峰统一偏了多少”。改变分析上限和窗长后，转换声的第三个
  候选峰可在约 1.76–3.97 kHz 间变动；高长音的第一候选峰还紧贴 F0。
  这不足以可靠地决定整段搬移声道共振峰。高基频的谱采样会使这种估计困难，
  [Praat 文档](https://www.fon.hum.uva.nl/praat/manual/FAQ__Formant_analysis.html)和
  [Ton Wempe《Into Sound》](https://www.fon.hum.uva.nl/wempe/bookIntoSound/bookIntoSound2.pdf)也说明了分析假设和高基频限制。

音色目前定位为“转换后的局部频段/谐波包络变化，叠加部分后处理压暗”，没有直接调整全局 formant，
也没有混回原唱高频以掩盖问题。若继续处理这项，应做局部谱包络对照并听角色音色，而非继续训练或全局提亮。
证据在 `tmp/rvc-envelope-fix/tone-metrics.json`、`formant-sensitivity.json`、`tone-summary.json`、
`blue-158-161-tone.png`。
