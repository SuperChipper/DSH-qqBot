### 实际优化步数限制

检查训练 G 的 AdamW 状态，全部 560 个有状态参数的步数一致：B 为 1319 次，C 为 1278 次。
B 比 C 多 41 次有效 G 更新，约 3.2%。**这是同轮数控制，不是严格同优化步数控制。**
数据量、bucket 批次以及 fp16 更新行为都可能影响有效步数，不能只用文件名或 epoch 估算。
若 B 优于 C，不能把全部差异唯一归于补样；扩量前仍应消除这项差异或明确不确定性。
未擅自增加 C 轮数，也未把额外更新伪称为“相同 10 epoch”。

### 客观结果，只作定位

双检测器共同支持覆盖（RMVPE 与 CREPE 对音高相互支持的帧占目标有声帧）：

| 魔法女仆 90–93 秒 | 91.4% | 91.4% | 90.0% |
| CIRCE 样例 6–9 秒 | 88.9% | 91.2% | 91.7% |
| CIRCE 样例 14–17 秒 | 89.8% | 89.4% | 90.7% |

| Blue 177–180 秒 | 84.8% | 84.8% | 83.7% |
| Blue 212–220 秒 | 90.2% | 88.8% | 88.6% |
| 一段留出高音元音（aux1_006） | 45.6% | 99.2% | 49.1% |

结果显示“继续微调”本身也能改变部分指标，且 B 在部分高音生成/留出元音上比 C 更强。
CIRCE 这些音高覆盖指标没有呈现 B 对 C 的优势，不能把先前 B 对 A 的全部听感收益归于辅助数据。
高音元音仍来自辅助歌手；这些数值不衡量肥鱼音色相似度，不代替过耳验收，也不证明 Blue 已解决。
本轮未据此挑选更换默认模型。

试听比较要分别回答：A→C 是否改善，B→C 是否仍有差距，目标音色是否变淡，是否新增退步。

后续 B 对 C：整体 B 略好，Blue 无区别。未收到 A 对 C 的单独试听评分，不推断其听感关系。
