   扩量前再加同优化步数、仅旧素材的控制组，分离“补数据”与“多训练”的贡献。

## 2. 延后的目标素材扩量配额

下表为清理、去重和划分验证集之后，实际进入训练的新增目标SID素材，时长不计长静音与重复增广。
数量按每条约4秒估算，实际可用3–8秒完整短句；按合格时长验收，不机械凑条数。

| 优先级 | 类别 | 音区参考 | 合格训练时长 | 估算条数 | 主要问题 |
|---|---|---|---:|---:|---|
| P0 | 高假声长元音 | 约500–800 Hz | 4分钟 | 60 | 魔法女仆19–21秒的高假声音色、能量稳定 |
| P0 | 真假声/轻重声衔接 | 约350–780 Hz | 3分钟 | 45 | 转音、起落音、音区切换时的连续性 |
| P1 | 干净有力的持续唱句 | 约500–700 Hz | 2分钟 | 30 | My Blue Sky Home长音的干净角色音色 |
| P1 | 目标音色的中低音唱句 | 能稳定保持音色的约200–400 Hz | 2分钟 | 30 | 男声源转换后的中低音稳定与音色一致性 |
| P1 | 轻声起音、换气再进入 | 约400–700 Hz | 1分钟 | 15 | 轻声尾音、换气后的有声起音 |
| 合计 | | | **12分钟** | **约180条** | |

另准备约3分钟新的目标音色素材作为开发/验证集，不从上述12分钟中再扣；最后按原录制会话/原句分组确定比例。
采集毛时长至少预留筛选余量，不能把“合成了15分钟”直接等同于“已有12分钟训练＋3分钟验证”。

### 高假声60条的具体任务

- 元音：`a / e / i / o / u`各覆盖，不只收“啊”。
- 音符：C5≈523、D5≈587、Eb5≈622、F5≈698、F#5≈740、G5≈784 Hz。
- 每个“元音×音符”两条独立发声：一条较轻、一条清晰稳定，持续约3–5秒，保留自然起音和收音。
- 5元音×6音符×2条＝60条，约4分钟；同一条复制或机械变调不算新的独立发声。
- 目标SID的600–800 Hz真实有声覆盖先达到至少120秒；其中较轻与较清晰两类各至少45秒。
- 达不到某个音而出现尖叫、音色明显改变或合成崩坏时，记为缺口，不以错误样本凑数。

音区是采样参考，不是发声机制标签；同样600 Hz可能是不同唱法，必须听辨并记录。

### 衔接45条的任务

各约15条：轻声→清晰发声→轻声；连续上滑/下滑与小音程转音；落音→短换气→同音区再起音。
同时包含原唱真实的大音程跳进对照，避免训练/评估只奖励把所有八度变化抹平。
不要把衔接正中间切开，原始长会话、切片与父素材关系都保留。

### 歌词与辅音覆盖

长元音之外加入短原创唱句，覆盖`ma/mi/mu、na/ni/nu、la/li/lu、ha/he/ho`及正常塞擦音。
含英语的素材可覆盖`home、blue、sky、light、stay`等单词及`h、m、s、t、k`的起止，
确保“home”的元音到尾辅音被完整保留。普通说话与自然气声继续保留，纯气声不强行标有声F0。

## 3. 素材从哪里获得

### 有同音色歌唱素材时

优先使用目标音色本身的干净清唱/可控歌唱生成结果，逐条核实音色与原肥鱼参考一致。
只有真正同一目标身份的样本进入SID 0；其他歌手仍使用独立SID。

### 当前仅有普通TTS时：实际可先执行的替代路线

1. 保留原12分钟目标说话，不继续大量重复生成相似日常台本。
2. 新增4–6分钟干净辅助歌唱，覆盖500–800 Hz长音、轻声和衔接，用独立SID，采样占比先不超过20%。
   多SID能提供共享歌唱经验，但不能据此宣称目标SID已经学会对应假声；需要独立验证。
3. 如试目标说话的变调增广，先做小范围、经音色复核的实验，记作`pitch_aug`，总采样占比先不超过10%。
   不将普通说话升八度冒充真实高假声，也不把增广秒数计入上述120秒核心覆盖配额。
4. 现有GPT-SoVITS说话管线没有已验证的按音符持续歌唱能力。输入“啊啊啊”或改pitch参数，
   不能作为完成高假声补样的验收依据。需要能实际控制音符与时值的目标歌唱生成能力，或真正同音色歌唱素材。
5. 不把当前RVC有缺陷的翻唱输出重新喂回SID 0，避免把半频、破音和音色偏差变成训练目标。

这条替代路线可以先验证辅助歌唱覆盖是否有效，但达不到“已取得12分钟目标歌唱”的事实条件。
若hi训练来源后来找回，先重新审计覆盖，已有合格样本可抵扣配额，不重复凑量。

## 4. 整理和验收

- 保留源采样率的无损母版；训练预处理统一40 kHz单声道，HuBERT另用16 kHz分支。不因本轮补样同时换采样率/架构。
- 排除数字削波、强混响、伴奏泄漏和过重降噪伪影；分离后的清唱必须试听，文件名写“vocals”不等于已合格。
- 保留弱声、自然起音和收音；不把每条轻声单独猛拉到0.97峰值。新增集先统一增益策略，并保存原始动态。
- RMVPE提取后，600 Hz以上长音和所有八度分歧逐条复核；结合独立估计器、频谱及试听，不能只看两算法投票。
- 本地RVC实现中`2b-f0nsf`保存连续Hz，`2a_f0`保存量化F0；修正连续曲线后同步重算量化曲线，确保与音频/特征对齐。
- 先按原句/原会话/原歌曲划分训练与验证，再切片和增广。重叠片段、同一句各版本、变调副本都留在同一个集合。
- 用`source_group`去重统计有效秒数；强相关重复片段不能充当独立覆盖。
- 新素材用新目录。现有`prep_dataset.py`会清空原`corpus/wavs`，不应直接用于覆盖式混入；这是后续脚本改造项，本轮不运行。
- SID通过清单显式指定。现有`rvc_filelist.py`未匹配前缀时默认SID 0，新增辅助语料不能靠随意命名来分SID。
- 推理用的目标index单独以训练集SID 0特征建立，验证集和辅助歌手特征不混入；检索本身不按SID自动过滤邻居。

建议清单字段见同目录`rvc-training-samples-template.csv`：保留身份、发声方式、音区、语言、来源组、生成/录制方式、
集合划分、有效有声秒数及人工F0/音色验收状态。CSV示例只是待采样任务，不是已获得素材。

## 5. 训练和对照顺序

1. **数据验收先于训练**：找回hi来源，或明确新实验可恢复的训练状态。保留线上hi及旧index作基线。
2. **先做便宜试验**：A＝重建的旧数据控制组；B＝A＋辅助歌唱；若取得目标歌唱，再做C＝B＋新增目标歌唱。
   A/B/C保持相同可用初始化、架构、随机种子和优化步数。当前hi另作为成品基准，不冒充同初始化的消融控制组。
3. 数据完整时，起始采样配比建议旧SID 0说话40%、新增SID 0歌唱40%、辅助SID 20%，按有效时长/采样权重控制。
   只有TTS的替代路线先用目标原素材80%、辅助20%；若试10%增广，则从目标原素材份额中拿出，不另超额增加。
4. 首轮先跑约1000–2000优化步作试验，每250–500步做固定验证；这是筛选窗口，不是保证收敛的推荐总步数。
   数据量变化后不以相同epoch假定相同训练量。若未见改善，先回查音色/F0标签，不仅延长训练。
5. 每个模型使用自己的目标SID训练index，固定比较index=0和0.6两档；不为每首歌另挑最优参数掩盖模型差异。
6. 第一轮保持推理预处理、亮化和混音相同，隔离模型改善；第二轮再评估是否可减轻后处理。

## 6. 固定验收集

先固定人工复核的目标F0，隔离生成器/训练改善；再跑自动F0端到端，单独统计提取错误。
两种结果分开报告，训练好坏不能替代推理音高纠错。

| 来源 | 窗口 | 重点 |
|---|---|---|
| 魔法女仆 | 19–21秒 | 约740–790 Hz高假声的音色、气噪、能量与稳定性 |
| 魔法女仆 | 26–29、44–46秒 | 快速转音、八度衔接 |
| 魔法女仆 | 90–93秒 | 同一角色声部的音区连续性 |
| My Blue Sky Home | 153–162秒 | 干净音色优先的高音长元音及嘶吼干扰 |
| My Blue Sky Home | 175–180秒 | home起尾及人工确认的约311 Hz音区；旧622 Hz目标已撤回 |
| CIRCE | 既定30–60秒基准 | 换气后高音重入，不降低已正确的轻声 |
| 男声基准 | BV1V8Hf6VEAK前25秒 | 保持既定人声+12/伴奏0策略时的目标音色 |
| 新目标验证素材 | 独立约3分钟 | 训练外假声、衔接、中低音与普通说话身份 |

现有已反复调参窗口只作回归集；最后再留未反复用于选模型的新句子/新歌曲作盲测。
验证素材和其派生版本不进入训练或检索index。

验收先看逐句：没有新增八度错误、弱声没有被擦掉、高音没有持续塌陷、目标音色没有明显漂移；
再做等响度干声/混音盲听。全曲中位误差、训练loss、某一pYIN置信度都不能单独决定上线。
仍有争议的假声保留旧版对照，不用“统计PASS”替代听感。
