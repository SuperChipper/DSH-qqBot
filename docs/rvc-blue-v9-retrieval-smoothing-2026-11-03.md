# Blue V9：尾段沙裂、发抖与电音感的局部对照

用户指出 V8 尾段试听第 3–5、7–9 秒仍有问题，即原曲 203–205、207–209 秒，
并明确其听感为**沙裂、发抖或电音感**。本轮不将这些描述直接归为转调错误。
已生成 V9 候选与同条件 A/B 对照，**尚未通过过耳验收**。

## 不改旋律的控制实验

源人声与伴奏裁出 202–210 秒，沿用 V8 的原目标曲线、模型 A、index=0.6、protect=0.35、
rms_mix=0.15 和其它润色参数。A/B 均固定随机种子 20261103，并在共同模块导入后重新设种子，
减少模型采样噪声对比较的影响；没有宣称消除了所有 GPU 数值非确定性。

- A `feature_control`：原检索推理。
- B `feature_smooth`：只在检索加权得到的特征向量上，加 0.25/0.5/0.25 的三帧时间平滑。
  特征帧长 20 ms；要求当前帧和两侧有声，且相邻 F0 变化均小于 1.5 半音。
  不改清音帧的检索特征，不在明确跳音的中心强行平滑，不改原始 HuBERT 特征支路。

两个推理实际导出的 `02_f0.csv` 逐字节相同；完整目标与 V8 逐字节相同。
本轮没有新混回原唱声音，没有改变模型、检索文件或检索强度，没有训练。

平滑只在诊断子进程内，通过 AST 精确匹配并检查唯一一处检索加权赋值后插入，
没有写入或替换安装目录里的 RVC 源码。
主流程仍使用原有 GPU 文件锁。`v9-output-check.json` 已核对线上三份回退代码哈希不变。

## 检查结果与限制

输入包含模型所需的反射填充，共 699 个检索特征帧，其中 596 帧满足平滑条件。
符合条件的相邻帧特征距离均值从 2.8668 降至 1.6111，约降低 43.8%。
这是特征空间的变化指标，包含填充上下文，**不是用户两个问题窗口的听感改善百分比**。
不能以向量更平滑推断更像肥鱼或破音已经消失；尤其还需听咬字是否变糊。

实际最终干声的逐帧回归：

| 区间 | A 可比帧 | B 可比帧 | A/B 绝对偏差超过 1 半音帧 | A/B 相对目标八度分歧帧 |
| --- | ---: | ---: | ---: | ---: |
| 203–205 秒 | 198 | 198 | 0 / 0 | 0 / 0 |
| 207–209 秒 | 195 | 194 | 4 / 4 | 3 / 2 |

第二处目标曲线仍含极短的约 139 Hz 帧，而输出多保持约 278 Hz。
因此这些分歧不能直接当成新旋律错误；也不能据此宣称目标完全正确。
本轮只检查 B 没有增加明显音区异常，不按这些数值判定沙裂、发抖或电音感已改善。

## 其它排查为什么未采用

对相同种子、原目标做了 index=0.2/0.6/0.9 的检索强度对照，但频带比例、采样差分变化
不足以选择听感更好的档位，最终 A/B 保持相同 index=0.6。

另外提取 HP5 主唱参考，发现 203 秒部分转音中它能提供更稳定的低音区，
但同时会丢失约数百毫秒的内容，208 秒附近还会发生倍频。
因此未直接替换 RVC 输入，也未采用按它重拟整段 F0 的方案。
用户明确听感后，继续保留原曲音符，把检索特征平滑作为独立候选，避免又把音色问题调成错误旋律。
